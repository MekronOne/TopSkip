# Top Skip

![Top Skip](TopSkip.png)

Расширение для автоматической простановки оценок в журнале [Top Academy](https://journal.top-academy.ru). Расширение работает автоматически при открытии формы оценки урока: выбирает нужную звезду, при необходимости добавляет комментарий, нажимает «Далее» и «Отправить», после чего ждёт следующую форму.

## Возможности

- Автоматическая оценка урока выбранным рейтингом от 1 до 5
- Необязательный комментарий к оценке
- Автоматическое заполнение формы домашнего задания без отправки финальное подтверждение остаётся за пользователем
- Повторная обработка каждой новой формы оценки
- Настройки сохраняются в `storage.local` и применяются без перезапуска страницы
- Совместимость с Chrome, Firefox(Manifest V3)
- Тёмная панель управления.

## Установка в Firefox (временно, до первого перезапуска браузера)

1. В адресной строке введите: `about:debugging#/runtime/this-firefox`
2. Нажмите кнопку «Загрузить временное дополнение…» (Load Temporary Add-on…)
3. В диалоге выберите файл manifest.json из папки ~/top-skip
4. Расширение появится в списке под заголовком «Временные расширения»

## Установка

Готовые архивы лежат в разделе [Releases](https://github.com/MekronOne/TopSkip/releases/latest):

- `TopSkip-3.0.zip` — для Chrome (распакованное расширение);
- `TopSkip-3.0.xpi` — для Firefox (неподписанный XPI; требует подписи в Mozilla или Dev Edition/Nightly).

## Настройки

| Настройка | Описание | По умолчанию |
|---|---|---|
| Оценка | Звезда, которую нужно ставить | `5` |
| Оставлять комментарий | Добавлять текст в поле комментария | выключено |
| Текст комментария | Текст комментария к оценке | пусто |
| Автоматически применять | Включение и пауза автоматизации | включено |
