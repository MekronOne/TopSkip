# Top Skip

![Top Skip](TopSkip.png)

WebExtension для автоматической простановки оценок в журнале [Top Academy](https://journal.top-academy.ru). Расширение работает автоматически при открытии формы оценки урока: выбирает нужную звезду, при необходимости добавляет комментарий, нажимает «Далее» и «Отправить», после чего ждёт следующую форму.

## Возможности

- Автоматическая оценка урока выбранным рейтингом от 1 до 5.
- Необязательный комментарий к оценке.
- Автоматическое заполнение формы домашнего задания без отправки — финальное подтверждение остаётся за пользователем.
- Повторная обработка каждой новой формы оценки.
- Настройки сохраняются в `storage.local` и применяются без перезапуска страницы.
- Совместимость с Chrome, Firefox и LibreWolf (Manifest V3).

## Установка

### Firefox / LibreWolf

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение».
3. Выберите `manifest.json` из папки проекта.

Временное дополнение сбрасывается после перезапуска браузера — это ограничение режима разработчика.

### Chrome

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.

## Настройки

Панель управления выполнена в тёмной теме.

| Настройка | Описание | По умолчанию |
|---|---|---|
| Оценка | Звезда, которую нужно ставить | `5` |
| Оставлять комментарий | Добавлять текст в поле комментария | выключено |
| Текст комментария | Текст комментария к оценке | пусто |
| Автоматически применять | Включение и пауза автоматизации | включено |

Тайминги ожидания элементов подобраны эмпирически. На медленном соединении или при изменении вёрстки сайта их может потребоваться увеличить в `content.js`.
