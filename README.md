# Top Skip

![Top Skip](TopSkip.png)

WebExtension для автоматической простановки оценок в журнале [Top Academy](https://journal.top-academy.ru). Расширение работает автоматически при открытии формы оценки урока: выбирает нужную звезду, при необходимости добавляет комментарий, нажимает «Далее» и «Отправить», после чего ждёт следующую форму.

## Возможности

- Автоматическая оценка урока выбранным рейтингом от 1 до 5.
- Необязательный комментарий к оценке.
- Автоматическое заполнение формы домашнего задания без отправки — финальное подтверждение остаётся за пользователем.
- Повторная обработка каждой новой формы оценки.
- Настройки сохраняются в `storage.local` и применяются без перезапуска страницы.
- Совместимость с Chrome, Firefox и LibreWolf (Manifest V3).
- Тёмная панель управления.

## Установка навсегда

Готовые архивы лежат в разделе [Releases](https://github.com/MekronOne/TopSkip/releases/latest):

- `TopSkip-3.0.zip` — для Chrome (распакованное расширение);
- `TopSkip-3.0.xpi` — для Firefox (подписанный или для Dev Edition/Nightly).

### Firefox

В обычном Firefox нельзя навсегда установить неподписанное расширение: браузер требует подпись Mozilla. Есть два постоянных способа.

#### Способ 1. Подписать XPI в Mozilla (рекомендуется)

1. Скачайте `TopSkip-3.0.xpi` из Releases.
2. Откройте [addons.mozilla.org/developers](https://addons.mozilla.org/developers/) и войдите в аккаунт Mozilla.
3. Нажмите «Submit a New Add-on» и выберите самостоятельное распространение (unlisted / «On your own»).
4. Загрузите `TopSkip-3.0.xpi` и дождитесь автоматической проверки и подписи.
5. Скачайте подписанный `.xpi`-файл.
6. В Firefox откройте `about:addons`, нажмите шестерёнку → «Install Add-on From File…» и выберите подписанный файл.

После установки расширение сохраняется между перезапусками браузера и обновляется как обычное дополнение.

#### Способ 2. Firefox Developer Edition или Nightly

Подходит, если не хотите публиковать расширение в Mozilla.

1. Установите Firefox Developer Edition или Nightly.
2. Откройте `about:config` и создайте параметр `xpinstall.signatures.required` со значением `false`.
3. Скачайте `TopSkip-3.0.xpi` из Releases.
4. Откройте `about:addons`, нажмите шестерёнку → «Install Add-on From File…» и выберите XPI.

В обычном Firefox этот способ не сработает — там проверку подписи отключить нельзя.

#### Временная установка (не сохраняется после перезапуска)

Для быстрой проверки можно открыть `about:debugging#/runtime/this-firefox`, нажать «Load Temporary Add-on» и выбрать `manifest.json`. После закрытия браузера расширение исчезнет.

### Chrome

Chrome не устанавливает сторонние `.crx`-файлы с GitHub, поэтому используйте распакованное расширение.

1. Скачайте `TopSkip-3.0.zip` из Releases.
2. Распакуйте архив в постоянную папку, например `~/TopSkip` или `C:\TopSkip`. Не удаляйте эту папку после установки.
3. Откройте `chrome://extensions`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение» и выберите папку, где находится `manifest.json`.

Расширение сохраняется после перезапуска Chrome. При старте браузер может показать предупреждение о расширениях в режиме разработчика — нажмите «Оставить» (Keep), чтобы оно не отключалось.

Для установки без предупреждений и автоматических обновлений расширение нужно опубликовать в Chrome Web Store. Это требует аккаунта разработчика Chrome.

### LibreWolf

В LibreWolf можно включить установку неподписанных XPI:

1. Откройте `about:config`.
2. Установите `xpinstall.signatures.required` в `false`.
3. Установите `TopSkip-3.0.xpi` через `about:addons` → шестерёнка → «Install Add-on From File…».

## Удаление

### Firefox

1. Откройте `about:addons`.
2. Найдите **Top Skip**.
3. Нажмите три точки рядом с расширением → «Remove» / «Удалить».

Если расширение было загружено временно, удалите его на странице `about:debugging#/runtime/this-firefox` кнопкой «Remove».

### Chrome

1. Откройте `chrome://extensions`.
2. Найдите **Top Skip**.
3. Нажмите «Удалить» / «Remove».

После удаления можно также удалить папку, в которую распаковывался архив.

## Обновление

- **Firefox:** установите новый подписанный XPI поверх старой версии или дождитесь обновления из Mozilla.
- **Chrome:** замените файлы в папке расширения и нажмите кнопку обновления на `chrome://extensions`.
- **LibreWolf:** установите новый XPI через `about:addons`.

## Настройки

| Настройка | Описание | По умолчанию |
|---|---|---|
| Оценка | Звезда, которую нужно ставить | `5` |
| Оставлять комментарий | Добавлять текст в поле комментария | выключено |
| Текст комментария | Текст комментария к оценке | пусто |
| Автоматически применять | Включение и пауза автоматизации | включено |
