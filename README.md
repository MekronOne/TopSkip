# Top Skip

![Top Skip](TopSkip.png)

Расширение для автоматической простановки оценок в журнале [Top Academy](https://journal.top-academy.ru). Расширение работает автоматически при открытии формы оценки урока: выбирает нужную звезду, при необходимости добавляет комментарий, нажимает «Далее» и «Отправить», после чего ждёт следующую форму. Окно оценки при этом скрыто от пользователя, но автоматизация продолжает с ним работать.

## Возможности

- Автоматическая оценка урока выбранным рейтингом от 1 до 5
- Необязательный комментарий к оценке
- Автоматическое заполнение формы домашнего задания без отправки — финальное подтверждение остаётся за пользователем
- Повторная обработка каждой новой формы оценки
- Окно оценки занятия не показывается, но оценка проставляется автоматически
- Окно «У вас есть непрочитанные объявления!» закрывается автоматически и не показывается при любых настройках
- Визуальные фильтры: блокировка рекламы и просроченных заданий
- Настройки сохраняются в `storage.local` и применяются без перезапуска страницы
- Совместимость с Chrome, Firefox (Manifest V3)
- Тёмная панель управления с анимированными переключателями.

## Установка в Firefox (временно, до первого перезапуска браузера)

1. В адресной строке введите: `about:debugging#/runtime/this-firefox`
2. Нажмите кнопку «Загрузить временное дополнение…» (Load Temporary Add-on…)
3. В диалоге выберите файл manifest.json из папки ~/top-skip
4. Расширение появится в списке под заголовком «Временные расширения»

## Установка

Готовые архивы лежат в разделе [Releases](https://github.com/MekronOne/TopSkip/releases/latest):

- `TopSkip-3.6.zip` — для Chrome (распакованное расширение);
- `TopSkip-3.6.xpi` — для Firefox (неподписанный XPI; требует подписи в Mozilla или Dev Edition/Nightly).

## Настройки

| Настройка | Описание | По умолчанию |
|---|---|---|
| Оценка | Звезда, которую нужно ставить | `5` |
| Оставлять комментарий | Добавлять текст в поле комментария | выключено |
| Текст комментария | Текст комментария к оценке | пусто |
| Автоматически применять | Включение и пауза автоматизации | включено |
| Блокировать рекламу | Скрывать истории, баннеры и рекламные логотипы | выключено |
| Убрать просрочки | Скрывать просроченные задания в списке домашних работ | выключено |

Настройки «Блокировать рекламу» и «Убрать просрочки» — **только визуальные**. Они скрывают элементы интерфейса и не меняют оценки, домашние задания или другие данные на сайте и сервере.

Окно оценки занятия скрывается всегда и не зависит от настроек. Автоматизация при этом продолжает выбирать оценку и отправлять форму в фоне.

## Сборка архивов

```bash
python3 scripts/build.py
```

Скрипт читает версию из `manifest.json` и создаёт в `dist/` файлы `TopSkip-<версия>.zip` и `TopSkip-<версия>.xpi`.

## Структура

```text
.
├── manifest.json   # Manifest V3
├── content.js      # автоматизация на странице журнала
├── popup.html      # панель настроек
├── popup.css       # тёмная тема панели
├── popup.js        # загрузка и сохранение настроек
├── icons/          # иконки 16×16, 48×48, 128×128
├── scripts/        # сборка архивов
└── dist/           # архивы для установки
```
